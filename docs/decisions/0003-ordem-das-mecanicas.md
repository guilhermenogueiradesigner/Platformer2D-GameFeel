# 0003. Ordem de introdução das mecânicas

**Data:** 2026-11-21 · **Status:** aceita

## Contexto

A fase ensina quatro mecânicas sem texto. A ordem em que elas aparecem define a curva de aprendizado: cada mecânica nova precisa se apoiar no que o jogador já domina.

## Opções consideradas

- **Pulo duplo → Parede → Dash → Gancho:** primeiro o eixo vertical, depois o horizontal, com o gancho como clímax.
- **Dash → Pulo duplo → Parede → Gancho:** começa pelo mais simples de entender, mas o dash sozinho tem poucas variações.
- **Parede → Pulo duplo → Dash → Gancho:** abre com a mecânica mais ligada à geometria, mas exige precisão logo no início.

## Decisão

**Pulo duplo → Parede → Dash → Gancho → Desafio final.**

## Por quê

O pulo duplo é a extensão mais natural do pulo, então é a porta de entrada. A parede usa o pulo duplo para subir poços. O dash em 8 direções chega depois de o jogador já pensar na vertical, e soma com o pulo duplo para alcançar lugares mais distantes. O gancho é a mecânica mais complexa e mais vistosa, por isso fecha a sequência antes do desafio final.

## Consequências

- Cada trecho da fase segue apresentação → prática segura → variação, e o desafio final combina as quatro.
- Os desafios de cada trecho podem exigir as mecânicas anteriores, nunca as seguintes.
